

# Agrivision AI

Agriculture plays a crucial role in ensuring food security and supporting economic growth. However, predicting crop yield accurately is a complex task because it depends on several interrelated factors such as soil properties, weather conditions, rainfall patterns, temperature variations, fertilizer application, and farming techniques. Conventional crop yield estimation methods mainly rely on farmers’ experience or historical averages, which often fail to capture the complex and dynamic nature of agricultural environments, leading to unreliable results.

To overcome these limitations, this project presents an AI-based Crop Yield Prediction System that utilizes machine learning techniques to analyze large and diverse agricultural datasets. The proposed system considers multiple input parameters, including rainfall, temperature, soil pH, crop type, and cultivation practices, to develop robust predictive models. Advanced machine learning algorithms such as Random Forest and XGBoost are employed to improve prediction accuracy and reliability. By delivering precise yield forecasts, the system helps farmers and agricultural planners make informed decisions related to crop selection, resource management, and risk reduction, ultimately contributing to enhanced agricultural productivity and sustainability.

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Run the app:
   `npm run dev`
